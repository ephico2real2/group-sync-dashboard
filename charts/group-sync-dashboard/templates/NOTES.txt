{{- $expire := include "gsd.cookieExpire" . }}
Sessions: the proxy cookie lives {{ $expire }} from login, and it is ABSOLUTE — there is
no cookie refresh and no mid-session revalidation, so an active reader is signed out at
that mark too, and a revoked user keeps access until it. Change it with
oauthProxy.cookie.expire. Signing out revokes the OAuth token itself, so it does not
merely forget the session.
