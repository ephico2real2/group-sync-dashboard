NOTE: replicaCount is {{ .Values.replicaCount }}. Each pod polls for itself and owns its own

Authentication: OpenShift OAuth. Anyone who can log into this cluster can view the
dashboard{{ if .Values.oauthProxy.sar }}, subject to the SubjectAccessReview in oauthProxy.sar{{ end }}.

{{- $expire := include "gsd.cookieExpire" . }}
Sessions: the proxy cookie lives {{ $expire }} from login, and it is ABSOLUTE — there is
no cookie refresh and no mid-session revalidation, so an active reader is signed out at
that mark too, and a revoked user keeps access until it. Change it with
oauthProxy.cookie.expire. Signing out ends the proxy session; it does NOT revoke the OAuth
token, because this chart authenticates as a ServiceAccount whose tokens carry only
user:info and user:check-access — the DELETE was built, measured returning 403, and dropped.
{{- $oauthCR := lookup "config.openshift.io/v1" "OAuth" "" "cluster" }}
{{- if $oauthCR }}
{{- $tc := (($oauthCR.spec) | default dict).tokenConfig | default dict }}
{{- $maxAge := $tc.accessTokenMaxAgeSeconds | default 86400 }}
{{- if gt (float64 (include "gsd.durationSeconds" $expire)) (float64 $maxAge) }}

WARNING: the cookie lifetime ({{ $expire }}) exceeds this cluster's
accessTokenMaxAgeSeconds ({{ $maxAge }}s). Nothing rechecks the token mid-session, so the
cookie would outlive the token it represents and API calls fail before sign-out does.
Lower oauthProxy.cookie.expire.
