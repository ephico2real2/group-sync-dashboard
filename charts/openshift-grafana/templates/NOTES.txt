  kind: GrafanaDashboard
  spec:
    instanceSelector:
      matchLabels:
        app.kubernetes.io/instance: {{ .Release.Name }}
    datasources:
      - inputName: DS_PROMETHEUS
        datasourceName: {{ .Values.thanos.datasource.uid | quote }}   # the uid: substituted verbatim into the panels
    configMapRef: {name: <your-configmap>, key: <your-file>.json}

User-workload monitoring is the one prerequisite (cluster-admin, once per cluster). Without it the
user-workload Prometheus does not exist and Thanos serves no user metrics: the datasource is green,
the panels are empty. If it is not on yet, run (or add the key to the existing ConfigMap's config.yaml):
  oc -n openshift-monitoring create configmap cluster-monitoring-config --from-literal=config.yaml='enableUserWorkload: true'
