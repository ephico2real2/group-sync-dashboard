# Reports — end-to-end walks of the deployed dashboard

One folder per walk, named `YYYY-MM-DD_<slug>`, holding what a walk produced and the scripts that
produced it: the documents the report service generated (PDF/A, HTML, JSON), every screenshot at full
resolution, the walk document with the pictures embedded, and the results files every number in that
document was read from. This is evidence, not documentation: `../docs/` says what the product does; a
folder here says what it did on a given day, on a named cluster, at a named commit.
