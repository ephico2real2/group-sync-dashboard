Rejoin shared-qa

Sign in to shared-qa as yourself. The dashboard logs in once to https://api.crc.testing:6443, reads the poller's token, writes gsd-cluster-shared-qa, and signs that login out. Your username and password are used for this one login and are not stored — not in the Secret, not in a log line, not in this page.

  • passed 1 · this cluster (the host)
    You hold the cluster-admin tier here — update clusterrolebindings — which is why Rejoin is shown to you at all.
  • decided there 2 · shared-qa (the remote)
    shared-qa's own RBAC, under your login, decides whether you may read group-sync-operator/group-sync-dashboard-cluster-poller-token. A cluster-admin there can. If shared-qa refuses you, this dashboard cannot override it.
One try per password. If shared-qa refuses this password, it is not sent to shared-qa again. A locked directory account answers HTTP 500, not 401, so trying again only locks it further.
