Your dashboard session has ended.

Signing out asks the cluster to revoke the access token this dashboard was using, the same way the OpenShift web console does. If that request could not be made — the session had already expired, or the cluster did not answer — the token is not revoked early and instead expires on the cluster's own schedule.

Only this dashboard is signed out. Your sessions in the OpenShift web console and the oc command line are separate and still active, and depending on the cluster's identity provider you may or may not be asked for your password the next time you sign in here.
